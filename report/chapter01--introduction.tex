The SUT is a small online shopping system written in java, that manages shopping carts, applies discounts and coupons, calculates delivery fees, and produces an order summary with the final amount payable.

\section{Testing objective}
The objective was to find and document faults by testing the supplied
system against its requirements. Testing focused on discount, coupon,
and delivery rules and their effect on the final amount payable.

\section{Methodology}
\begin{enumerate}
    \item \textbf{Requirement grouping.} The 14 requirements were
    grouped by behaviour. Priority was given to rules whose interaction
    could change what a customer pays.
    \item \textbf{Functional baseline.} Test inputs were selected using
    decision tables and boundary values. Expected results were derived
    from the brief. JUnit tests exercised individual classes and orders
    using real services. Mockito was used to isolate the order service
    and check which total it passed to delivery.
    \item \textbf{Structural testing.} Baseline line and branch coverage
    was measured with JaCoCo. Missed decisions were traced through the
    source code and decision-to-decision graphs. Tests were then added
    for reachable paths such as the rejection of a negative delivery total.
    \item \textbf{Final results and fault documentation.} Final coverage
    was compared with the baseline, and remaining gaps were recorded.
    Each fault was documented with its exposing test, expected and
    observed behaviour, and the source class and line numbers. The
    production code remained unchanged.
\end{enumerate}

\section{Technology Stack}
\begin{itemize}
    \item \textbf{Java 21} was used to compile and run the supplied application
    and the test suite.
    \item \textbf{JUnit 4.13.2} was used to run the tests and check whether
    results and exceptions matched the expected behaviour.
    \item \textbf{Mockito 1.9.5} was used to isolate the order service and verify
    that it passed the final discounted total to the delivery service.
    \item \textbf{JaCoCo 0.8.15} measured line and branch coverage and generated
    the HTML reports used to compare the baseline and final test suites.
    \item \textbf{Visual Studio Code} was used to develop the tests, inspect
    failures, and run the coverage tasks.
\end{itemize}
