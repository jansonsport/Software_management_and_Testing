The SUT is a small online shopping system written in java, that manages shopping carts, applies discounts and coupons, calculates delivery fees, and produces an order summary with the final amount payable.

\section{Testing objective}
The objective was to find and document faults by testing the supplied
system against its requirements. We focused on discount, coupon, and
delivery rules and how they affect the final amount payable.

\section{Methodology}
\begin{enumerate}
    \item \textbf{Group the requirements.} We grouped the 14 requirements
    by behaviour and prioritised rules whose interaction could change
    what a customer pays.
    \item \textbf{Design and run the functional baseline.} We used
    decision tables and boundary values to select inputs and derived
    expected results from the brief. We wrote JUnit tests for individual
    classes and for orders using real services. We also used Mockito to
    isolate the order service and check what total it passed to delivery.
    \item \textbf{Inspect coverage and add structural tests.} We used
    JaCoCo to measure baseline line and branch coverage. We traced missed
    decisions through the source code and decision-to-decision graphs,
    then added tests for reachable paths such as rejecting a negative
    delivery total.
    \item \textbf{Rerun and document the findings.} We compared the
    final coverage with the baseline and recorded any remaining gaps.
    For each fault we documented the exposing test, the expected and
    observed behaviour, and the source class and line numbers. The
    production code remained unchanged.
\end{enumerate}

\section{Technology Stack}
\begin{itemize}
    \item \textbf{Java 21} was used to compile and run the supplied application
    and the test suite.
    \item \textbf{JUnit 4.13.2} was used to run the tests and check whether
    results and exceptions matched the expected behaviour.
    \item \textbf{Mockito 1.9.5} was used to isolate the order service and verify
    that it passed the final discounted total to the delivery service.
    \item \textbf{JaCoCo 0.8.15} measured line and branch coverage and generated
    the HTML reports used to compare the baseline and final test suites.
    \item \textbf{Visual Studio Code} was used to develop the tests, inspect
    failures, and run the coverage tasks.
\end{itemize}
